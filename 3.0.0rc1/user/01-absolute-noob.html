Getting started

Welcome to the absolute beginner's guide to py-fatigue! If you have comments or suggestions, please don't hesitate to file an issue or make a pull request on our GitHub repo: https://github.com/OWI-Lab/py_fatigue/.

Welcome to py-fatigue!

py-fatigue was originally part of the DYNAwind suite of tools for wind turbine structural health monitoring and analysis. The tool has been detached from the project and now relies on the following PyPi packages only:

  • [numpy]{.title-ref}
  • [pyecharts]{.title-ref}
  • [pandas]{.title-ref}
  • [matplotlib]{.title-ref}
  • [pydantic]{.title-ref}

The package bundles the main functionality for performing cyclic stress (fatigue and crack growth) analysis and cycle-counting.

Installing py-fatigue

py-fatigue is freely available on GitHub and gets maintained through CI/CD phylosophy. Py-Fatigue 3 targets 64-bit CPython 3.10–3.14. A source build requires Rust.

To install the toolbox from PyPI, simply run:

pip install py-fatigue

and you will get the latest published version.

How to import py-fatigue

To access py-fatigue and its functions import it in your Python code like this:

import py_fatigue as pf

Static and interactive plots

Use .plot() for a Matplotlib figure and axes, or .echarts() for an interactive chart. Both methods take the same domain inputs, such as the intensity samples to evaluate a NASGRO curve.

Object What its plot shows
CycleCount Rainflow histogram. Use plot_type to select the axes.
SNCurve, ParisCurve, WalkerCurve, NasgroCurve The material curve, including any supplied measurement overlay for S–N, Paris, or Walker curves.
Plate, cylinder and infinite-surface geometries A sketch using the dimensions supplied to the geometry.
CalcCrackGrowth from get_crack_growth Crack depth recorded at the start of each legacy step.
GrowthResult from simulate_crack_growth Accepted crack dimensions against cumulative cycles.
df.miner and df.gassner Contributions by stress range after calculating Miner damage or Gassner shift factors. 
from py_fatigue import SNCurve

curve = SNCurve(slope=3, intercept=12.0)
fig, ax = curve.plot()
fig.savefig("sn-curve.png")
curve.echarts().render("sn-curve.html")

For material curves, pass scale="loglog", scale="semilogx", or scale="semilogy" to either method. The semilog options put the x or y axis on a logarithmic scale, respectively. S–N, Paris, and Walker curves default to log–log. NASGRO defaults to a logarithmic growth-rate axis.

Use to_echarts(fig) from py_fatigue.plotting when you have composed several plots into an existing figure. Pass to_echarts(ax) for a single panel. The HTML includes hover, zoom, reset and PNG export, and loads ECharts from the pyecharts CDN.

For calculations that display a mean stress correction figure, pass a callback to plot to receive the figure and render it separately.

from py_fatigue.plotting import to_echarts

def save_interactive(fig):
    to_echarts(fig).render("mean-stress.html")

corrected = cycle_count.mean_stress_correction(plot=save_interactive)

How to use py-fatigue

The main functionality of py-fatigue is to perform cyclic stress analysis and cycle counting. The toolbox provides a number of functions to perform these tasks. The main functions are:

  1. `cycle_count`: collects all the functions related with cycle-counting fatigue data and allows a simpler representation of a rainflow-counted stress vs. time history.
  2. `material`: allows the definition of some fatigue-specific material properties such as

a. SN curve and b. Paris' law.

  1. `geometry`: enables the instantiation of specific crack geometries for crack propagation analysis, i.e.

a. Infinite surface. b. Hollow cylinder with a crack on its external surface.

  1. `damage`: the module collecting the fatigue life calculation models.

a. `stress-life`: fatigue analysis based on the cycle-counting and SN curve. b. `crack_growth`: crack propagation (growth) analysis based on the cycle-counting, the Paris' law and the geometrical definition of a crack case (defect geometry and medium).

  1. `mean_stress`: a module to calculate the mean stress correction factor for the cycle-counting.
  2. `testing`: a module to simulate different kinds of load histories. The most generic type of load history can be simulated using the [get_sampled_time]{.title-ref} and [get_random_data]{.title-ref} functions, as shown in the example below.

Example

In the following example, starting from a randomly generated signal, we will:

  • calculate the rainflow
  • export the cycle-count matrix
  • reconstruct the CycleCount object from the exported matrix
  • define the SN curve
  • calculate the Palmgren-Miner damage
  • define the Paris' law
  • define a crack geometry
  • run a crack growth analysis.

The damage and crack growth analyses will be also executed by means of the pandas DataFrame accessors that [py-fatigue]{.title-ref} implements.

Random signal simulation

import py_fatigue as pf
import py_fatigue.testing as test

# Simulate a random signal
t = test.get_sampled_time(duration=10000, fs=10)
s = test.get_random_data(
    t=t, min_=-30, range_=180, random_type="weibull", a=2., seed=42
)
# Plot the signal
plt.plot(t, s, 'k', lw=0.5)
plt.xlabel("Time, s")
plt.ylabel("Signal, MPa")
plt.show()

Crack growth

A crack growth simulation necessitates of three ingredients (objects):

  • Cycle-counted stress history
  • Crack growth curve (e.g. Paris' law)
  • Crack geometry

Paris' curve definition

SIF = np.linspace(1,2500, 300)
SLOPE = np.array([2.88, 5.1, 8.16, 5.1, 2.88])
INTER = np.array([1E-16, 1E-20, 1E-27, 1E-19, 1E-13])
THRESHOLD = 20
CRITICAL = 2000
pc = pf.ParisCurve(slope=SLOPE, intercept=INTER, threshold=THRESHOLD,

Working with pandas DataFrames

It's possible to translate the CycleCount object to a pandas DataFrame and use the implemented accessors py_fatigue.damage.stress_life.PalmgrenMiner ([miner]{.title-ref}) and py_fatigue.damage.crack_growth.CrackGrowth ([cg]{.title-ref}) to perform the stress-life and propagation analyses as shown above.

import pandas as pd

df = cycle_count.to_df()

# Stress-life
df.miner.damage(sn_curve=c_air)
# Crack-growth
df.cg.calc_growth(cg_curve=pc, crack_geometry=geo)

df.miner.plot_histogram()


df.plot(kind="scatter", x="cumul_cycle", y="crack_depth", s=2)
