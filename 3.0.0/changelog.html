Changelog¶

3.0.0¶

  • Replace Numba with Rust numerical kernels and provide native wheels for 64-bit CPython 3.10–3.15. The rainflow regression suite verifies exact agreement with Py-Fatigue 2.1.1.
  • Retain the public fatigue classes and pandas accessors. The migration guide covers code that used Numba-specific helpers.
  • Add ordered NASGRO crack growth for supported plate, shell, bar, thread, and plate-hole geometries. Verify TC01 life and SC01 crack shape and depth history against published membrane-tension benchmarks. The crack-growth guide gives the supported load and geometry limits.
  • Add SEP005 and pyExSi stress-history connectors for cycle counting and fatigue analysis.
  • Preserve the input unit when summing cycle counts or recovering residual cycles. Discussion #27
  • Move the documentation to Zensical and the examples to marimo. The notebooks include Matplotlib and ECharts views, synthetic histories, and AFGROW handbook comparisons.
  • Update the Rust bindings to PyO3 0.30.1 and Rust NumPy 0.30.0.

3.0.0rc2¶

  • Add CPython 3.15 support and stress-history connectors for SEP005 and pyExSi.

  • Use imported stress histories for cycle counting and Paris crack growth.

  • Replace the inherited ASTM rainflow routines with Rust and verify exact agreement with Py-Fatigue 2.1.1 on the rainflow regression checks.

  • Include Rust dependency license notices in the wheels and source archive.
  • Run Paris crack growth with tabulated geometry factors and report a geometry-limit stop at the final tabulated crack dimension.
  • Add end-to-end marimo tutorials for stress-life and crack-growth analysis. Compare Py-Fatigue with the AFGROW handbook's MERC-3, FAC-1, and blend-out repair examples.

Install this candidate explicitly with pip install py-fatigue==3.0.0rc2.

3.0.0rc1¶

This release candidate moves numerical kernels to Rust and adds ordered NASGRO crack growth for plate, shell, bar, thread, and plate-hole geometries. See the crack-growth guide for the supported loads and limits of each solution.

The documentation uses Zensical. The marimo examples provide Matplotlib and ECharts views, synthetic histories, and comparisons with the AFGROW handbook.

Install this candidate explicitly with pip install py-fatigue==3.0.0rc1.

Historical unreleased notes from 2.x¶

  • Cache generic Numba root-finder specializations, add opt-in warmup_numba(), and enable disk caching for direct Numba kernels.
  • Support Numba 0.61 through 0.65 on Python versions below 3.14 and Numba 0.65 on Python 3.14.
  • Fix pandas 3.x compatibility in cycle-count aggregation and notebook examples.
  • Update the Numba performance report, repair docs links, and run the tutorial notebooks on Python 3.13 and 3.14.
